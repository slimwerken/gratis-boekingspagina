# Boekingspagina

Dit is een gratis boekingspagina (Calendly-vervanger) op Convex.

- **Nog niet geinstalleerd?** (geen `.env.local`, of `convex/instellingen.ts` staat nog op "Jouw Naam") Volg dan `INSTALLEER-MIJ.md`, sectie "Voor Claude: de wizard".
- **Al geinstalleerd?** Zie `INSTALLEER-MIJ.md`, sectie "Voor Claude: later onderhoud".
- Alles wat per persoon verschilt staat in `convex/instellingen.ts`. Na een wijziging: `npm run uitrollen`.
- Sleutels nooit in een bestand of in de chat herhalen; ze staan in de Convex-omgeving.
- Pas `convex/pagina_html.ts` nooit met de hand aan; die komt uit `pagina/index.html`.
